# Retro Portfolio

A brutalist, retro-styled portfolio website built with Next.js, Tailwind CSS v4, and Framer Motion.

## Features

- **Storeytelling Scroll**: A central path connects all sections, growing as you scroll.
- **Retro Aesthetic**: Custom "RetroBox" components with hard shadows and thick borders.
- **Interactive**: Scroll animations and hover effects.
- **Tech Stack**: Next.js App Router, Tailwind v4, Framer Motion.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser.

## Customization

- **Content**: Edit the component files in `components/` to update your information.
- **Styles**: Tweak `app/globals.css` or `components/ui/RetroBox.tsx` for visual changes.
